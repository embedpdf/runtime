## Upstream changes outside the conflicts

- **Numbers in content streams (`9ce000987`).** Upstream writes floats with Dragonbox, the shortest
  form that reads back exactly: `.3` instead of `.30000001`. Everything that writes content goes
  through it, our content rewriter and generators too, so their output bytes change; four of our
  content-rewrite expectations moved with it (Tests).
- **Saved pages in embedder tests (`17c6f449c`).** `LoadSavedPage()` / `CloseSavedPage()` became
  private; our 80 calls in four test files use `LoadScopedSavedPage()`. Where a test closed the
  page before closing the saved document, the page now lives in its own block.
- **Skia's `SkLog()` calls `SkLogHandler::GetInstance()`** after the roll; our `redaction_pathops`
  subset builds `src/utils/SkLogHandler.cpp` too (a never-set atomic handler; see Globals).
- **JPEG decoding no longer patches an image stream's bytes** (write audit). Found by the write
  audit on code upstream moved; the behaviour predates the sync.
- **Codecs reorganized** around optional Rust decoders (BMP, PNG, JPEG) and a split libjpeg
  decoder; all Rust options stay off in our builds (they need Rust, and JPEG needs Skia).
- **New APIs:** `FPDFBookmark_GetStyle()`, `FPDFPath_GetBezierControlPoints()`.

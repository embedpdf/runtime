## Upstream changes outside the conflicts

- **Object-tree traversal (`1799c8d53`):** after the trailer, it also traverses the document's
  catalog if the trailer didn't reach it (they can differ after an xref rebuild). Our only callers
  are the page content generator's shared-object checks, in the default mode; our save path doesn't
  use this traversal. On a layer, `GetRoot()` is the catalog the trailer's `/Root` resolves to, so
  nothing is traversed twice.
- **JPEG rewind (`4f93283fe`):** re-reading a JPEG header on rewind must keep the dimensions,
  components and scale it started with, and libjpeg's row width must fit the scanline buffer;
  otherwise decoding stops. In `libjpeg_scanline_decoder.cpp`, which we don't change.
- **Font name records (`3351236ec`):** the TrueType name table parser read the platform ID twice,
  so Windows (UTF-16) name records were skipped. Fonts named only that way now report their names.
- **Lab ICC profiles (`30b2a20a5`):** an ICC-based image with a Lab profile failed to build its
  transform; it now converts.
- **Mirrored characters (`03ad8222f`):** `GetMirrorChar()` handles supplementary-plane characters;
  merged into our `fx_unicode.cpp` (rich-text).
- **FreeType roll (`145911ae9`, 36 commits)**, including a Type 1 private-dictionary leak fix. The
  embedder tests come out the same.
- **`ConvertBuffer()` without `src_left`/`src_top` (`82a14a9c3`)**, `FxDataPartitionType` and the
  reworked `FX_DATA_PARTITION_EXCEPTION` (`711dc444a`, `892b0f37e`, `c75f0bd27`): our code calls
  neither the old signature nor the macro.
- **JavaScript platform calls (`c7348a4dd`, `6d4647835`, `9976ca5f8`):** guarded against nesting;
  merged into our `cpdfsdk_formfillenvironment.cpp`. V8 isn't in our builds.
- Not in our builds: XFA (`02829e813`, `ba50ddfbc`, `7adf81f40`, `87989d71d`, `21d549947`), the
  libyuv `SwapXY()` path on wasm32 (`5a31c5c34`), Skia's `cfx_dibbase_skia.cpp` (`77b522a2c`,
  `b3c6c6f4b`), riscv64 (`13af78b6e`, `08d305717`). Many new unit tests, all passing.

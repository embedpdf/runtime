EPDFRedactEmbedderTest.FullyRemovedSpanLeavesNoPropertyOrStructureResidue BUG (rule view-scope): EPDFPage_ApplyRedactions reads references without a CPDF_DocumentViewScope (ApplyAllRedactionsCore), so it can read the base's old version of an object the layer changed.
EPDFAnnotEmbedderTest.ApplyRedactionFallsBackToRectForNonFiniteQuad BUG (rule view-scope): applying a redaction (EPDFPage_ApplyRedactions) reads references without a CPDF_DocumentViewScope.
